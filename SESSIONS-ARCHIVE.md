### 2026-07-14 (сессия 1 — ревизия приложения + фича «Гаммы / лады» + настройка деплоя Netlify↔GitHub)

После — настроили деплой: репозиторий на GitHub + связка с существующим Netlify-проектом для авто-деплоя. В конце — создание этого CLAUDE.md по аналогии с магазином Poigraem.

**Что сделано:**
- **Полная ревизия `index.html`** — программная проверка всех музыкальных данных (боксы, 120 VOICINGS, генератор, ритмы). База в отличном состоянии, ошибок нот нет. Найдены 6 багов (регистровые скачки прогрессий, ресайз рамок, громкость после лимитера, синхронный KS, мёртвый count-in, мелочи) + улучшения звука. Всё зафиксировано в «Найденных багах» выше.
- **Фича «Гаммы / лады»** (пункт 3) — новый блок «3. Расширь до гаммы / лада»: `SCALES` (7 ладов, строка 535), селектор `renderScaleSel`, добавленные ноты гаммы (фиолетовые `.nb.ext`) и характерная нота лада (оранжевая `.nb.char`) поверх пентатоники, карточка `renderScaleInfo` (ноты + жанр + подсказка «как обыгрывать»), легенда, интеграция с подсветкой тонов аккорда. Прогрессии перенумерованы (3→4). Локрийский честно убирает квинту с грифа. selScale в localStorage со сбросом при смене минор/мажор.

- **Деплой Netlify↔GitHub** — создан репозиторий `github.com/enterteinment42/penta-trainer`, файл залит через браузер (drag-and-drop, без токена), существующий Netlify-проект `penta-trainer` (раньше Netlify Drop) связан с Git через Continuous deployment → Link repository. Проверено: файл в репо идентичен оригиналу (`git clone` + `diff`), деплой прошёл (`main@d66b35c`).
- **Создан этот `CLAUDE.md`** — адаптация брифинга Poigraem под одно-файловый проект без backend: убраны разделы VPS/Supabase/безопасности/параллельных сессий, сохранены команды сессий (`/session-start`, `/session-end`, `/session-archive`), добавлена команда `/audit`.

**Что решили:**
- Главная цель приложения — импровизация и джем, всё ей подчинено. Каждая фича проходит тест «помогает ли во время джема».
- Гаммы/лады подаются не как справочник, а через настроение + жанр + характерную ноту, с несколькими уровнями глубины (минор+2 ноты → полный лад). Объединили бывшие пункты 3 и «обучение ладам» в один.
- Музыкальные данные проверяются программно, не на глаз (легко ошибиться на полутон).
- Деплой Public-репозиторием (нет ничего чувствительного, проще для Netlify).

**Новые баги:** баг ALL-режима с ладом (окно ext-нот) — найден и исправлен в этой же сессии до деплоя.
